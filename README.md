# 인용 카탈로그 (Citation Catalog)

논문 PDF를 업로드하면, 본문에서 사용된 모든 참고문헌에 대해 그 참고문헌이 인용된 문장들을 모아서 정리해주는 도구입니다.

- 배포판 (Claude Artifact): https://claude.ai/code/artifact/ceca1b51-2419-4dbb-87af-398f3be6dcbb
- 로컬 실행: `index.html`을 브라우저로 그냥 열면 됩니다 (별도 서버·빌드 과정 없음).

## 주요 기능

- **PDF 업로드 → 자동 분석**: [pdf.js](https://mozilla.github.io/pdf.js/)로 브라우저 안에서만 텍스트를 추출합니다. 파일이 서버로 전송되지 않습니다.
- **여러 인용 표기 스타일 자동 인식**
  - 대괄호 숫자형: `[1]`, `[2,3]`, `[4-6]`
  - 괄호 숫자형: `(1)`, `(3,10,11)` (의학 저널에서 흔한 방식)
  - 위첨자 숫자형: 대괄호·괄호 없이 작고 위로 떠 있는 숫자만 있는 경우 (PDF 안의 폰트 크기·좌표를 비교해서 감지)
  - 저자-연도형: `(Smith, 2020)`, `(Kim et al., 2019; Lee, 2021)`
- **참고문헌 시작 위치 자동 감지** — "References"가 `R E F E R E N C E S`처럼 글자가 벌어진 형태로 조판되어 있어도 인식
- **본문 시작 위치(Introduction) 자동 감지** — 제목·저자·소속·초록 등 앞부분을 스캔 대상에서 제외해서, 저자 소속 번호 같은 위첨자를 인용으로 오인하지 않도록 함
- **두 가지 보기 + 상호 검증**
  - 참고문헌별 보기: 참고문헌마다 그걸 인용한 문장들을 모아서 표시
  - 문장별 검토: 문장마다 매칭된 참고문헌 번호를 나열 (예: `[2-5,7]` → `2 3 4 5 7`로 펼쳐서 표시), 잘못된 매칭은 그 자리에서 칩을 지우거나 추가해서 수정 가능
- **진단 패널** — 본문에는 있는데 참고문헌 목록에서 못 찾은 인용 / 목록에는 있는데 본문에서 안 쓰인 참고문헌을 따로 표시
- **Markdown 내보내기** — 검토·수정이 끝나면 결과를 `.md` 파일로 저장 (Claude Artifact의 `downloads` 캡ability 사용, 로컬 `index.html`에서는 이 버튼이 비활성 안내만 뜸)

## 알려진 한계

- 정규식·휴리스틱 기반이라 완벽하지 않습니다. 문장 분리, 저자·연도 인식이 논문마다 다르게 어긋날 수 있어 "문장별 검토" 탭으로 사람이 확인하는 걸 권장합니다.
- 스캔된 이미지 PDF(텍스트 레이어 없음)는 지원하지 않습니다.
- 표(table) 셀 안에 있는 인용은 PDF 텍스트 추출 순서가 뒤틀리는 경우가 많아 놓칠 수 있습니다.
- Results 섹션의 신뢰구간처럼 대괄호/괄호를 인용이 아닌 다른 용도로 쓰는 경우 오탐이 생길 수 있습니다 (문장별 검토에서 수정 가능).

## 기술 스택

순수 HTML/CSS/JS 단일 파일이며 빌드 과정이 없습니다. 외부 의존성은 pdf.js(cdnjs)와 Google Fonts(Spectral, Work Sans, IBM Plex Mono)뿐입니다.
